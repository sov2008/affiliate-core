## Architecture & Technical Overview

This deployment architecture establishes a hardened, leak-proof browser environment designed to bypass advanced anti-fraud engines (such as Akamai, Cloudflare, and F5) that monitor affiliate traffic and ad accounts. By replacing naive API blocking with dynamic noise injection and strict proxy-bound WebRTC routing, this configuration prevents browser fingerprinting correlation without triggering heuristic anomaly flags. The resulting setup ensures that each anti-detect profile maintains a unique, highly trusted digital identity, eliminating sudden account bans and tracking discrepancies.

## Step-by-Step Implementation

### Step 1: Initialize the Profile via API with OS-Hardware Alignment

To prevent fingerprint mismatching, you must programmatically initialize your anti-detect profiles. This ensures that the User-Agent, Client Hints, WebGL metadata, and hardware concurrency values are perfectly aligned.

Below is a production-ready Node.js script utilizing an anti-detect local API (e.g., AdsPower or Multilogin) to provision a hardened profile:

```javascript
import axios from 'axios';

const API_URL = 'http://local.adspower.net:50325/api/v1/user/create';

async function createHardenedProfile(profileName, proxyHost, proxyPort, proxyUser, proxyPass) {
  const payload = {
    name: profileName,
    group_id: "0",
    user_proxy_config: {
      proxy_soft: "other",
      proxy_type: "socks5",
      proxy_host: proxyHost,
      proxy_port: parseInt(proxyPort),
      proxy_user: proxyUser,
      proxy_password: proxyPass
    },
    fingerprint_config: {
      automatic_timezone: "1", // Syncs timezone with proxy IP
      language_type: "1",      // Syncs language with proxy IP country
      webrtc: "forward",       // Routes WebRTC through proxy, spoofing public IP
      canvas: "1",             // Enables Canvas Noise Injection (1 = Noise, 2 = Block)
      webgl: "1",              // Enables WebGL Noise Injection
      webgl_metadata: "1",     // Spoofs WebGL Vendor and Renderer
      audio: "1",              // Enables AudioContext Noise Injection
      client_rects: "1",       // Enables ClientRects Noise Injection
      device_name_switch: "1", // Spoofs local device name
      media_devices: "1",      // Spoofs connected media devices (mics, cameras)
      cpu_concurrency: "8",    // Aligns hardware threads
      device_memory: "8"       // Aligns RAM allocation (in GB)
    }
  };

  try {
    const response = await axios.post(API_URL, payload);
    if (response.data.code === 0) {
      console.log(`[SUCCESS] Profile created. ID: ${response.data.data.user_id}`);
      return response.data.data.user_id;
    } else {
      throw new Error(`API Error: ${response.data.msg}`);
    }
  } catch (error) {
    console.error(`[ERROR] Profile creation failed:`, error.message);
  }
}

// Example Execution
createHardenedProfile(
  "AdOps_Prod_Profile_01",
  "residential.proxyprovider.com",
  "10001",
  "user-country-us",
  "secure_password_123"
);
```

> **Warning:** Never hardcode static hardware values (like `cpu_concurrency: "8"` or `device_memory: "8"`) across all profiles if your User-Agents represent mobile devices. A mobile User-Agent claiming 8 cores and 16GB of RAM is an immediate anomaly.

### Step 2: Configure Hardened WebRTC Routing Policies

If you are managing custom Chromium builds or configuring profiles via Puppeteer/Playwright flags, you must enforce strict WebRTC routing policies. 

Add the following Chromium command-line switches to your browser launch configuration to prevent local IP leaks while keeping the WebRTC API active:

```bash
# Force WebRTC to use only the proxy-assigned IP address
--force-webrtc-ip-handling-policy=default_public_interface_only

# Disable local IP address enumeration over WebRTC
--disable-webrtc-multiple-routes=true

# Prevent the browser from exposing local network interfaces via mDNS
--enable-features=WebRtcHideLocalIpsWithMdns
```

> **Critical Note:** Do not use `--disable-webrtc` or set `media.peerconnection.enabled` to `false`. Modern web applications (including Facebook Ads Manager and Google Ads) actively query the `RTCPeerConnection` object. If the object is missing or disabled, your trust score drops to zero, triggering immediate verification checkpoints.

### Step 3: Implement Dynamic Canvas Noise Injection

When using custom automation frameworks (like Playwright with vanilla Chromium), you must inject a script at document start to intercept Canvas rendering calls and inject subtle, consistent noise. This prevents tracking engines from generating a static, identifiable Canvas hash.

Save this script and inject it as an initialization script (`page.addInitScript` in Playwright):

```javascript
// canvas-noise-injector.js
(function() {
  const injectNoise = (canvas) => {
    const ctx = canvas.getContext('2d');
    if (!ctx) return;

    // Intercept getImageData to inject subtle noise into readback operations
    const originalGetImageData = ctx.getImageData;
    ctx.getImageData = function(sx, sy, sw, sh) {
      const imageData = originalGetImageData.apply(this, arguments);
      const data = imageData.data;
      
      // Inject pseudo-random, deterministic noise based on coordinate offsets
      for (let i = 0; i < data.length; i += 4) {
        // Apply extremely subtle shift to the least significant bits of RGB channels
        data[i]     = data[i]     ^ (sx & 1); // Red
        data[i + 1] = data[i + 1] ^ (sy & 1); // Green
        data[i + 2] = data[i + 2] ^ (sw & 1); // Blue
      }
      return imageData;
    };

    // Intercept toDataURL to prevent raw canvas hash extraction
    const originalToDataURL = canvas.toDataURL;
    canvas.toDataURL = function(type, encoderOptions) {
      // Force a tiny rendering change before export
      ctx.fillStyle = 'rgba(255,255,255,0.01)';
      ctx.fillRect(0, 0, 1, 1);
      return originalToDataURL.apply(this, arguments);
    };
  };

  // Override the HTMLCanvasElement prototype
  const originalGetContext = HTMLCanvasElement.prototype.getContext;
  HTMLCanvasElement.prototype.getContext = function(type, contextAttributes) {
    const context = originalGetContext.apply(this, arguments);
    if (type === '2d') {
      injectNoise(this);
    }
    return context;
  };
})();
```

### Step 4: Automate Fingerprint Verification

Before routing production traffic, run an automated verification script to ensure that the browser profile does not leak its true IP or display inconsistent fingerprint hashes.

```javascript
import { chromium } from 'playwright';

async function verifyProfileHardening(wsEndpoint) {
  // Connect to the running anti-detect profile instance
  const browser = await chromium.connectOverCDP(wsEndpoint);
  const context = browser.contexts()[0];
  const page = await context.newPage();

  console.log("[INFO] Navigating to leak test endpoint...");
  await page.goto('https://browserleaks.com/webrtc', { waitUntil: 'networkidle' });

  // Extract WebRTC Local and Public IPs from the DOM
  const localIP = await page.locator('#rtc-local-ip').innerText();
  const publicIP = await page.locator('#rtc-public-ip').innerText();
  
  console.log(`[VERIFICATION] WebRTC Local IP: ${localIP}`);
  console.log(`[VERIFICATION] WebRTC Public IP: ${publicIP}`);

  if (localIP.includes('192.168.') || localIP.includes('10.')) {
    console.error("[ALERT] WebRTC Leak Detected: Local IP is exposed!");
  } else {
    console.log("[SUCCESS] WebRTC Local IP is successfully masked.");
  }

  // Navigate to Canvas fingerprinting test
  await page.goto('https://browserleaks.com/canvas', { waitUntil: 'networkidle' });
  const canvasHash = await page.locator('#canvas-hash').innerText();
  console.log(`[VERIFICATION] Canvas Hash: ${canvasHash}`);

  await browser.close();
}
```

## Diagnostics & Common Pitfalls

### Pre-Flight Verification Checklist
Before allocating ad budget or initiating automated actions, verify the profile against these four diagnostic tests:
1. **IP-to-WebRTC Geolocation Match:** Ensure the country code of your proxy IP matches the WebRTC STUN server IP country code.
2. **CreepJS Trust Score:** Navigate to `https://miroslavpejic85.github.io/creepjs/` and verify that the trust score is above **60%** and no "API tampering" flags are present.
3. **DNS Leak Test:** Run a DNS leak test to confirm that DNS queries are routed through the proxy's DNS servers, not your local ISP's DNS.
4. **AudioContext Latency Consistency:** Ensure that the AudioContext fingerprint is modified but stable across page reloads within the same profile.

### Common Failure Modes & Rectifications

#### 1. The "Disabled WebRTC" Trap
* **Symptom:** Ad accounts get flagged or hit with immediate phone verification checkpoints upon login.
* **Root Cause:** WebRTC is completely disabled in the profile settings. Anti-fraud scripts detect that `window.RTCPeerConnection` is undefined or blocked, which is a highly anomalous state for modern residential users.
* **Rectification:** Change the WebRTC setting from `Disabled` to `Forward` or `Manual`. Ensure that the STUN server queries resolve to the proxy IP, not your local IP.

#### 2. Static Canvas Noise Signature
* **Symptom:** Multiple profiles are linked together by anti-fraud systems, leading to chain bans.
* **Root Cause:** The canvas noise generator uses a static seed or a predictable pattern. The resulting canvas hash, while unique compared to real hardware, is identical across all of your profiles.
* **Rectification:** Ensure your anti-detect browser or custom injection script uses a dynamic, profile-specific seed to generate unique noise offsets for each individual profile.

#### 3. Proxy DNS Leaks
* **Symptom:** The profile's IP address shows as United States, but the target platform detects your true physical location.
* **Root Cause:** The browser is resolving domain names using your local router's DNS servers instead of routing DNS queries through the SOCKS5/HTTP proxy.
* **Rectification:** Force DNS resolution through the proxy. In Chromium-based setups, ensure the proxy configuration is set to resolve DNS remotely (e.g., using the `--proxy-server` flag with SOCKS5 protocol prefix: `socks5h://`).
