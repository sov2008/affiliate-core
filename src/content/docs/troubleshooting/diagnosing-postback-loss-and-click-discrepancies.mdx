## Problem Identification

Discrepancies between traffic source stats (Meta, Google, TikTok, Propeller) and tracker conversions typically stem from one of three architectural vectors:
1. **Network Latency & Drop-offs**: Slow landing page redirects losing mobile users before pixel/S2S execution.
2. **SubID Stripping**: Redirect loops or unencoded query strings dropping the `click_id`.
3. **Timezone Offset**: Mismatch between affiliate network server reporting (e.g., UTC-5) and tracker reporting (UTC+0).

---

## Triage Checklist

- [ ] Verify that `sub1` or `click_id` is properly URL-encoded across all redirect hops.
- [ ] Check Nginx/Cloudflare SSL handshake latency (under 100ms recommended).
- [ ] Inspect raw webhook logs for HTTP 400/403 rejections on incoming callbacks.
- [ ] Verify that conversion deduplication isn't prematurely discarding multi-tier payouts.

---

## Diagnostic Script

Run this verification script on your edge proxy to inspect incoming postback payload headers:

```bash
tail -f /var/log/nginx/postback_access.log | grep -E "(click_id|subid|payout)"
```
